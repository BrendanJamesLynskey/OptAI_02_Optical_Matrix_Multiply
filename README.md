# Optical Technology for AI Processing 02 — Optical Matrix Multiply: Precision and Conversions

Pricing an optical matrix–vector product conversion by conversion: encoding and storing values, where noise sets precision, the photon floor, why converters dominate, static power and utilisation, how arrays scale and drift, and the digital yardstick it has to beat.

Topics: Reuse, Weight storage, ENOB, Shot noise, Converters, pJ/MAC.
